Autonomous Line-Following Robot

LEGO MINDSTORM EV3 · PID Control Algorithm

National Champion at Robofest Ghana 2025.

Designed and implemented a PID (Proportional-Integral-Derivative) control algorithm for autonomous line navigation, a core precursor to reinforcement learning control systems. Tuned Kp, Ki, and Kd parameters through iterative testing to achieve sub-second course correction at high speed.

Optimized sensor-motor feedback loops under strict competition time limits, simulating the real-world constraint of deploying ML models with latency requirements.

Solar-Powered Automated Water Dispenser

Arduino · Ultrasonic Sensors · C++ · Solar Panel

Team project (3+ members). Built a solar-powered water dispensing system using dual ultrasonic sensors to detect container placement and automatically control a solenoid valve. The system monitors fill level in real time and closes the valve when the container is full or removed.

Implemented debounce logic to prevent false triggers, a buzzer for audio feedback, and LED status indicators. The entire system runs off-grid on solar power, suitable for deployment in areas without reliable electricity.
